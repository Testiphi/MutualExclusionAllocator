# 擂台表解锁 A 方案交互演示

直接打开 index.html，无需服务器或依赖。仅使用虚构地图、车辆和成绩，模拟账号状态在内存中保存，刷新恢复初始值。不访问网络、现有账号库、贡献账本、工作簿或正式数据，不使用 localStorage。

顶部可切换游客、即将解锁、一级待选地图、一级已选地图、二级全部开放。支持查看进度、确认或取消选图、查询筛选、空结果、切换状态和重置。投稿按钮仅说明将衔接现有投稿流程，不创建真实投稿。

门槛均为待确认草案：一级积分50且有效贡献5；二级积分150、有效贡献15且高质量5。有效质量>=6，高质量>=8。地图仅三组虚构样例，不代表真实目录或成绩范围。

这是 A 方案：展示查询权益，不保护已公开的底层成绩数据；所有演示记录本身也位于公开前端脚本中。模拟模型不是后端授权实现。国际服、真实计分联动、管理员授权和新通知不在本演示内。

本轮只做独立演示，不改仓库代码或数据，不提交推送、构包或上线。后续用户确认交互与规则后，再实施真实账号权限和只读表格接口。

model.js 与 demo.js 均通过 `node --check`。Node DOM模拟检查通过：门槛边界、取消和确认选图、积分不扣除、地图范围、分区/档位/跑法筛选、空结果、切换账号清空旧记录、进度页和重置。此证据不是浏览器视觉或手机验收。

内置浏览器的安全策略拒绝 file 协议，未改用其他方式绕过，未进行浏览器视觉检查。请直接用本机浏览器打开 index.html 体验：

1. 默认“即将解锁”，查看条件和进度。
2. 切到“一级 · 待选地图”，选一张地图，先取消再确认；查看开放成绩并切换到另一张锁定地图。
3. 切到“二级 · 全部开放”，体验小地图、分区、档位、跑法和车辆搜索。
4. 切回游客，确认旧成绩不再显示；点击重置恢复初始状态。
