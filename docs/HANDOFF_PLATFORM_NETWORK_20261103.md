# 隔离联网准备交接（网站 / 运维侧）

2026-11-03。小程序离线功能已由用户验收。下一步顺序固定为：真实微信访客会话与快照 → OCR → RacePick账号及云车库。本文是待协调清单，不表示已部署或授权修改生产。

## 域名和用户需要做的事

既有部署记录中的域名为 `racepick.cn`，无需再买域名。建议使用 `mini-test.racepick.cn` 作为隔离测试入口；这只是建议，尚未建立或核验解析、证书、服务和微信登记。也可以由运维给出另一个合适的现有子域名。

用户现在只需把本文交给网站 / 运维侧。不要先猜IP添加解析、修改正式网站或在聊天发送AppSecret。待对方给出确定入口及核验结果，再提供逐步微信后台与真机操作。原来的 `https://racepick.cn` 不能仅凭域名已有就视为原生接口已启用；正式账号和网页Cookie不作为测试身份。

## 第一阶段最小服务范围

1. 先只读核验现有服务器容量、域名解析、证书覆盖、运行进程与端口，再确定独立服务方案。同一台服务器可以评估复用，但必须隔离服务、状态目录和反向代理入口；不复制正式账号库、成绩状态或旧测试状态，不重启既有服务。按用户现有服务器协作方式，一次提供一个只读核验步骤，由用户执行回传，不提供成组生产写脚本。
2. 确定固定源码 / 数据来源及快照身份。访客接口按网站 `MINI_API_CONTRACT_20261102.md` 与 `MINI_DEPLOYMENT_20261102.md` 实现；账号与B–E桥接暂不开启。第一阶段仅需 `POST /api/mini/v1/session`、`GET /api/mini/v1/snapshot?server=cn|global`。`image_policy` 保持 `disabled`，快照可以明确声明不支持识图，不启动新的重复OCR队列/worker。
3. 新建隔离访客状态，匹配现有小程序AppID，在服务端私有文件配置AppSecret及真实微信代码交换。目录、密钥文件按部署要求限制运行用户权限（目录700、文件600或等效权限）；不写客户端、Git、聊天、访问日志或交付材料。不能使用fixture身份来宣布真实微信通过，不能靠AppID / Referer模拟身份。
4. DNS解析指向现场核验的入口；证书必须实际覆盖测试子域名，既有主域证书不一定覆盖它。可信HTTPS直接返回协议JSON，不跳转其他域名或网页登录，不用自签证书/跳过校验代替验收。保持原网页Cookie / Origin / CSRF规则；核验可信代理、Host、IP限流、响应和上传大小/时间限制，不做宽泛放行。
5. 特别注意：当前 `mini_local serve` 绑定127.0.0.1、关闭proxy_headers，且没有简单的公开Host配置入口。不能把本机fixture启动命令原样反代为公网服务。请网站侧确认适合网络基础阶段的隔离启动入口、Host/可信代理配置及轻量运行方式；若需后端改动，归网站分支实施并固定契约后回交，小程序分支不同时改公共文件。
6. 服务就绪后，由用户在微信后台登记实际HTTPS **request合法域名**。OCR阶段再核对uploadFile域名；私有证据阶段核对downloadFile域名，三者可采用同一已配置的测试主机。安全域名、审核进度、隐私指引和安全策略是否齐备必须按现场事实记录，不假定已通过。

## 请回交的非秘密信息

- 实际HTTPS origin（只有协议和主机，必要时端口，无API路径），固定源码提交、数据版本及快照SHA/身份。
- 隔离服务 / 新状态目录的核验摘要；确认没有引用正式库或改动既有服务。
- 服务端真实微信验证“已配置 / 未配置”及不含密钥的核验记录；不回传AppSecret、session_key、code、token或OpenID明文。
- 第一阶段图片策略disabled、账号/B–E未启用的实际状态；可信TLS、Host/代理与限流检查结果。合法域名登记由用户确认，配置声明不能代替实际SDK请求。

收到上述信息后，小程序侧生成独立网络检查工程，保留域名校验，用真实wx.login获取一次性代码，在内存交换访客token并核验两服原始UTF-8快照/SHA/字节。它不调用账号接口、不上传图片、不写本机车库。先开发者工具，再提供用户手动预览扫码的真机步骤，不自动上传体验版或提审。

## 后续OCR / 账号的提前准备

OCR仍使用访客token，不要求先登录RacePick账号。启用前需网站侧确定真实图片安全机制、平台隐私/用途声明和隔离执行容量；图片解码、OCR、成绩审批都不是内容安全审核。再按原8MiB任务协议接相册、原key恢复、五槽确认与前后台，不新建第二套模型/配额。不得为提前测试私自把公网图片策略改成private_unmoderated。

RacePick账号随后沿A契约独立接邮箱/密码、验证与分服云车库。使用新隔离测试账号与安全邮件方案；rpa1账号token与访客token严格分开，登录不自动导入游客车库。正式邮件、生产账号迁移、管理业务写入另按实际范围协调。

本次交接不授权DNS / Nginx / 生产部署、正式数据库迁移、微信后台操作、上传、提审或上线；这些操作没有在小程序侧执行。
