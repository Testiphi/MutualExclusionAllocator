# 上传区直接放到选车首页 · 2026-10-31

后续已按用户要求移除页面上的步骤、样例、验收说明、格式/到期小字及重复结果标签，见[上传区简化记录](MAP_UPLOAD_MINIMAL_20261031.md)。下文为此前内嵌阶段记录。

用户希望取消上传入口弹窗和多余操作。本轮改成首页常驻上传区，选择/拖入图片后自动识别，用户核对五槽后只需一次确认应用。旧上传按钮和截图弹窗从当前DOM移除；不打开新页面，不自动滚动跳转。

上传区在五行选图之前，样例折叠为可选入口。识别中可以继续使用现有手动选图；当前选图变化时，旧识别结果仍会被拒绝应用。确认后保留图片和五槽预览，显示已应用状态；可清空截图或重新识别，不强行关闭/跳走。清空不清除已选地图。

本地地址仍为http://127.0.0.1:8031/ ，刷新页面即可看到。生产未操作，尚未提交推送/合并或构包。

## 不同尺寸的实际边界

OCR输入按比例处理，小于1280宽的图统一等比放大，检测最长边1280；文字框还原至原图坐标。没有把平板拉伸成16:9，也不是只支持某个固定像素尺寸。

既有样本已覆盖1280×720、接近1920×1080、1567×1080和2420×1668等原图。9张960×540派生图通过；9张640×360派生图没有完整读齐，返回部分结果或拒绝。49/49原图为已知探索集，不是任意设备/尺寸的泛化保证。

接口限制8MB与1600万像素；当前布局解析要求宽至少600、高至少300、宽高比1.30–2.20，并检查已知页面标题、布局锚点、真实槽位和大小地图配对。进入这个范围不等于一定读齐。超宽屏、明显黑边、任意裁切、透视拍屏、未测语言/界面需专项验证；缺字不补图，保留手动修正。
