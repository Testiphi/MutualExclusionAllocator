## 回退条件与方法

识图启动失败、超时无法恢复、内存/磁盘超预算、原API被限流、账号/串服隔离失败、成绩/车库发生非预期改变、Nginx校验失败均停止推进。优先关闭OCR入口与worker，保留手动选图和原业务服务；保全队列/日志证据，禁止自动清理。

应用回退须选兼容现有coverage2/global-score1及其他现有组件的保留版本；只回退程序与本轮配套配置，不用旧包JSON覆盖score-state，不恢复旧业务库抹掉新增。Nginx恢复旧配置先nginx -t，按授权reload。整套业务数据恢复需另行授权并保全新增。
