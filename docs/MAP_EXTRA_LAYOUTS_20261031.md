2026-10-31，用户提供三张原图并授权适配：未进入挑战前的对手防守信息、纵向五行防御结果、纵向五行进攻结果。

## 实现

`backend/map_layout.py`新增opponent_preview、defense_rows、attack_rows三类布局。对手信息使用特定位置的“对手信息”标题与五卡横向网格；结算页使用“防御结果”或居中的挑战结果标题，按从上到下的五行读取中间地图列。车辆、左右成绩、昵称和ID不参与地图匹配，不能用它们补缺。

“对手信息”只在明确的前景标题位置进入新布局，未全局撤销弹窗保护；重新开始、冲突标题等仍拒绝。缺行/列保留真实空槽，不按读出数量重编号，额外行、第三个名字、目录歧义和重复地图不输出完整结果。原匹配阈值及正式地图目录未改，模型未替换/训练。
