## 实现

`parse_map_layout(image_size, ocr, catalog, server=..., catalog_version=...)`为只依赖Python标准库的纯函数；不加载OCR引擎、MaaFramework、数据库或设备，不读取文件名、车辆、成绩、历史帧和预期五图。

支持当前已验证的中文布局：资格赛展开五槽、挑战页展开横向标题、资格赛结果/失利五卡、防御五卡。使用实际文字位置、字号及比例几何定位；字体更大的地图标题或横向地图标题定位展开槽，五卡使用固定五列几何。缺失槽不会按识别结果数量重新编号。

按钮颜色、是否可点击、是否已经选车均不是前置。MA9原游戏执行守卫完全未修改。保留精确页面标题/弹窗检查、大/小地图共同匹配、备选歧义、跨槽/边界/第三行冲突和重复地图拒绝。

返回固定五槽：matched/unresolved/ambiguous，含原始文字框、名称相似度、原因、服别和目录版本。无执行许可字段，`needs_user_confirmation`始终为true；complete只表示当前五对及槽位完整，不能授权游戏或正式数据写入。相似度不是正确概率。定位锚点缺失时保守拒绝，不用剩余地图数猜编号。

字符、OCR行数、图片范围和目录条数有边界，非法输入返回拒绝结果，不留上一轮名称。当前比例适配是经过样本校准的布局模型，并非任意截图/透视/裁切自动校正；英文界面、真实微信设备及国际服实图尚未验证。
