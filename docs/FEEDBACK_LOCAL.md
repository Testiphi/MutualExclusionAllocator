## 功能范围

### 账号管理中的昵称

复用contribution_preferences，不新增第二套昵称数据。超级管理员账号列表增加自定义昵称和榜单展示方式（公开/匿名），未填写显示“未设置”，支持邮箱或昵称搜索，包括对%与_按字面匹配。停用、恢复及强退仍以稳定账号ID执行，确认提示保留邮箱。普通玩家和普通管理员无权读取账号清单。

昵称设置说明补充：匿名仅针对公开展示，站长仍能查看账号与昵称；公开榜隐私规则保持。没有启用贡献表的旧测试库返回空昵称，不自动迁移贡献表。

### 按钮外观

ui.css统一操作按钮和导航按钮的尺寸、圆角、颜色、焦点、禁用状态；主操作使用绿色，停用/强退/撤下等危险操作用红色区分。投稿、管理员邀请、账号管理、成绩版本、排行榜和预览页的返回入口统一为“返回选车助手”按钮外观，仍保留链接语义，支持复制地址及新标签页打开。正文来源、证据和引用链接继续作为文字链接。

### 文字反馈

- 玩家入口：个人中心 → 问题反馈；站长入口：管理工作台 → 用户反馈（显示待处理数量）。主页不追加独立反馈按钮。
- 登录且邮箱已验证的用户可创建和查看自己的反馈，只有超级管理员可查看全部、回复及调整状态。普通管理员不获得这项管理权限。
- 类型：功能异常、数据问题、使用建议、其他。标题和描述必填，复现步骤、预期/实际结果可选。
- 只附带账号、提交时间、来源页面路径及本地应用标记，表单可见；不收集日志、车库、浏览器信息或URL查询参数，不支持附件，不发送邮件。
- 状态：待处理、处理中、待补充、已解决、已关闭。用户在待补充/已解决状态补充后回到待处理；处理中补充保留处理中。关闭后不再接受用户回复，可新建反馈引用旧编号，站长仍可重新打开。
- 原始问题和全部回复/状态记录保留，使用textContent显示用户输入，不解释HTML。列表支持状态/标题筛选和分页，每页30条。
- 所有回复和状态更新需要revision，陈旧页面收到409；创建和回复采用用户范围内的request_key防重复，网络超时重试不重复写入。每账号24小时最多新建10条，每小时最多30次创建/回复事件（回复检查），超过时提示稍后重试。
- 反馈独立于成绩投稿、发布和贡献积分，不直接修改任何成绩或增加贡献分。成绩补充仍走原投稿入口。

## 用户验收步骤

同站点普通标签页共享登录状态，换账号应先在个人中心退出，或使用独立浏览器会话。

1. 用站长账号登录，管理工作台 → 账号与公告管理。应看到昵称“山路补图员”，另两个账号为“未设置”；搜索“山路”应只匹配玩家。按邮箱搜索仍可用。检查返回、分页、操作按钮外观与焦点。
2. 换玩家账号，在个人中心修改昵称或勾选匿名，再换站长查看账号列表：显示新昵称与“匿名”，而公开排行榜显示匿名贡献者。验证匿名不妨碍站长识别账号。
3. 玩家进入个人中心 → 问题反馈，新建一条标题、描述和步骤明确的本地模拟问题。提交后应看到反馈编号、待处理状态及自己的原始内容；已有反馈可以展开，能看到站长回复。
4. 换站长，管理工作台应显示待处理数量。进入用户反馈，按标题或状态筛选，填写用户可见回复，改为“待补充”并保存。
5. 换回原玩家，在原反馈里补充说明，状态应回到“待处理”，原问题及站长回复仍保留。
6. 站长可依次验证处理中、已解决和已关闭。已解决反馈若玩家继续补充会重新待处理；已关闭反馈不能继续回复，页面给出说明。所有状态更改须填写处理说明。
7. 普通管理员账号访问/admin-feedback应显示仅站长可用；无法通过接口读取全部反馈。它在自己的/feedback仅看到自己的记录。无需为本轮测试新增正式账号。
8. 回归主页车库、选车、投稿和排行榜；反馈操作不改变成绩或贡献分。不为本轮验收发布模拟成绩。
