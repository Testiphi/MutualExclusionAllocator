## 直接验收

本机地址：**http://127.0.0.1:8031/**，游客即可使用，无需注册登录。

1. 点击首页地图行上方的“上传截图”。
2. 可直接点“试用：灰按钮资格赛”“平板挑战页”“五卡结果页”；按钮会实际上传原图、排队并由独立worker运行真实v5 OCR，不是预置识别结果。
3. 结果弹窗显示五个槽位，核对大/小地图和顺序；可以修改任意槽位。确认前首页选图保持不变。
4. 点击“确认并填入五张地图”，一次性更新现有五行选图并复用原计算流程。保存车库、星级和正式成绩不参与本动作。
5. “低清截图（手动补充）”用于验收未识别/部分识别：补全全部五槽、排除重复大地图后才能应用。也可点“暂不应用”关闭，保留首页当前选图。
6. 可以选择自己的PNG/JPEG/WebP静态截图，最大8MB、1600万像素。图片不应被压到640×360后再期待五槽全自动成功；未知或歧义项交用户确认。

本机回环地址不能直接在手机上访问。390px为Chromium窄屏模拟验收，不是手机微信或小程序真机验收。

## 实现与边界

- `backend/map_recognition.py`：显式启用的本地任务API，独立SQLite任务库和私有图片；绑定当前会话身份、服别和目录版本。上传原始图片只对专用POST路径放行，原接口的JSON/Origin/CSRF边界保持。
- `backend/map_ocr_engine.py` / `map_ocr_worker.py`：独立CPU进程，复用冻结v5模型与本地vendor，校验哈希，禁止推理网络连接，不导入MA9/MaaFramework，不调用设备。单个demo目录只有一个worker。
- `map_recognition.js/css`：选择/预览、上传/等待/取消/重试、五槽手动修正、确认应用、暂不应用。更换选图/档位/账号上下文或会话/目录变化时拒绝旧结果覆盖。
- `index.html`：小范围选图桥接，完整校验后一次性应用，复用原选图唯一性与计算。不修改车辆/星级/估算或互斥算法。
- `auth.js`：仅新增只读身份访问器，供页面上下文比较；登录/角色规则不变。
- `tools/run_map_demo.py`：本地初始化与启动；默认应用不启用此功能，生产入口显式拒绝map_recognition配置。

任务最多每会话2个未完成、全局8个未完成；每会话10分钟20次提交；默认1小时到期。取消或关闭时尝试删除本次上传副本及结果，到期清理由运行中的worker/API执行；服务停止时不会凭空执行清理，重启后继续处理到期项。四个验收样例是独立拷贝，作为测试材料保留，不由上传TTL删除。原始用户文件、历史证据和其他资料从未被清理。

查询重试复用原任务，上传响应丢失时复用request_key，避免重复排队；取消/到期后，迟到的worker结果不能重新发布。worker退出会将未完成任务标为失败，手动选图继续可用；可重启demo后重新识别，不自动重放旧任务。
