## 发布范围

- 覆盖表每组48车、紧凑密度；参考车辆列优先，其余按实际覆盖数排序。高手每车一列，表头选择合法星级，不改车库。
- 不再整行公开地图成绩。按当前运行版本、服别/分区/档位/跑法，优先挑覆盖最多尚无参考行的车辆列；同分按总覆盖数/车名，直到有记录的默认满星行均被覆盖。筛选、翻页、星级选择不轮换参考车。普通跑法国服五区理论3列/高手7列、四区理论5列/高手9列；国际理论3列。四区高手原有2行没有全车满星记录，继续留空。不得把此范围描述成旧版每图一条或整行免费。
- 空格复用原投稿页：鼠标单击进入；触屏首次轻点后格旁提示再次填写，再点同格进入，滑动取消，无底部按钮。游客登录后直达预填页，只填成绩即可送审；说明/视频/图片可选，原批量与草稿折叠保留。沿用草稿、上传、revision、审核和贡献链，重试不重复创建已成功稿件或重复上传成功图片。审核仍必须人工，不自动写成绩或加分。
- 同类站内入口统一按钮外观，保留链接语义。不改原样式基线、数据库结构、解锁门槛、车辆/地图/估算规则。国际仍仅浏览，不支持投稿或国服贡献权益。
